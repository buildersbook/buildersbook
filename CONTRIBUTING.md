# Contributing

Issues are welcome for errata, broken links, factual corrections, and questions about the method.

Pull requests require prior discussion. Open an issue to agree on scope before starting work.

This repository is built by one operator directing AI coding agents through planning, implementation, read-only verification, and cross-family adversarial review. Pull requests are reviewed against the same codebase checks and CI gates, including content validation, design-token and contrast checks, and the JavaScript budget. Run `pnpm validate` and `pnpm build` before submitting a pull request.

Essays are records: corrections are appended as dated notes, not edits to the body. Book chapters are versioned and revised.

Content is licensed under [CC BY-SA 4.0](LICENSE-CONTENT), and code is licensed under [MIT](LICENSE). Contributions are accepted under the same terms.

Report vulnerabilities through [SECURITY.md](SECURITY.md).
