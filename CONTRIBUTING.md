# Contributing

Issues are welcome for errata, broken links, factual corrections, and questions about the method.

For pull requests, open an issue first. Unsolicited pull requests are closed until the book's structure is settled.

Essays are records: corrections are appended as dated notes, not edits to the body. Book chapters are versioned and revised.
