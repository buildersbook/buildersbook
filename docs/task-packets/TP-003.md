## Hook Setup

Run `git config core.hooksPath scripts/hooks` once in every clone; this setting replaces `.git/hooks` entirely, so every future repository hook must live under `scripts/hooks/`.

The pre-push hook fails closed when `BUILDERSBOOK_PRIVATE_MANIFEST` is unset or invalid. `git push --no-verify` is an operator-only emergency override.

## Rationale

The private manifest never leaves the operator's machine. The scanner therefore runs locally at push time; CI must not expect the manifest and must not fail because it is absent.
