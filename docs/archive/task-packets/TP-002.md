## Findings

1. The session primer named `docs/specs/DEVELOPMENT-PLAN.md`, but the repository source of truth is `/DEVELOPMENT-PLAN.md`. The operator accepted the corrected path.
2. Token verification against mockup inline styles found every specified light/dark base value applied outside the rendered token table except dark `--surface: #1E1B15`, which was declared but never applied.
3. The mockup supplied no dark values for `--ink-secondary` or `--rule-strong`. The operator approved dark `--ink-secondary: #B8B1A3`.
4. Proposed dark `--rule-strong: #6F6859` was rejected because its 3.30:1 contrast against dark paper would overstate a hairline tier relative to light mode. The operator selected `#423E35` (approximately 1.7:1) to preserve mode parity; genuinely visible dark boundaries use `--ink-muted` instead.
5. Dark `--surface` decision closed by the operator on 2026-08-26: replace the shipped `#1E1B15` (approximately 1.07:1 against dark `--paper`) with `#29251C` (approximately 1.22:1). The new value restores approximately the same surface separation as light mode.
6. Registry-latest TypeScript 7.0.2 and ESLint 10.9.1 exceeded the peer ranges of Next.js 16.3.3's lint stack. The scaffold uses the newest compatible TypeScript 6.0.3 and ESLint 9.39.5; the deprecated `@types/flexsearch` stub was removed because FlexSearch ships its own types.
7. Fumadocs UI 16's `css/preset.css` cannot be imported as an isolated PostCSS entry because its generated rules apply Tailwind utilities. Importing `fumadocs-ui/css/style.css` supplies the required Tailwind context. Next.js 16.3's automatic `AGENTS.md` generation was disabled with `agentRules: false` to preserve the forbidden LEAD-V canon file.
8. Next/font exposes Source Serif 4's optical-size axis only in variable-weight mode. The normal and italic files therefore load as variable fonts with `opsz`, while the site assigns only the specified 400/600/700 normal and 400/600 italic roles. JetBrains Mono loads the specified 400/500/700 static weights.
9. **Contradicted by shipped code (SITE-P8/P8x F-4).** This finding originally claimed that Fumadocs MDX 15.3.1 accepted only an array for the typed global `remarkPlugins` option. The shipped callback form compiles, typechecks, and places the constrained plugin before the framework transforms, so that original claim is false.
10. Static FlexSearch returned four live results for `sample`: one page and one text result for each unpublished fixture. Both fixture routes returned HTTP 200; the content validator passed rendered HTML and processed Markdown representations.
11. Responsive verification used the in-app browser with explicit 1000px, 390px, 320px, and 500px effective CSS viewports. The 500px viewport is the reflow-equivalent of 200% zoom on a 1000px window because the in-app browser does not expose page-zoom control. At 1000px the measured grid was exactly 620px + 44px + 168px inside a 912px shell. At every narrow/zoom-equivalent viewport, document scroll width stayed within client width, titles stayed within the viewport, and two adjacent marginalia blocks had non-overlapping rectangles in logical order.
12. Stage 5 browser checks confirmed the copy button, overflowing `pre`, footnote reference, and backlink are all native keyboard-focusable controls (`tabIndex` 0). Copy activation reached `data-state="copied"` with the accessible name “Copied code”; the failure branch is handled by the same live region and retry label. Footnote and backlink activation updated each target hash, and the target received both background and a 2px outline.
13. At 320px, the deliberately long filename wrapped to 49.5px without crossing the copy control; the code region overflowed internally with `overflow-x: auto`, `tabIndex=0`, and no document overflow. The book index measured one `<li>` per logical row, `min-width: 0` on the title, and the state below the title in the narrow two-column grid.
14. Stage 6 visual review confirmed the shipped dark `--surface: #1E1B15` made the sticky header only faintly distinct from `--paper: #171511`. The operator closed the decision on 2026-08-26 in favor of `#29251C`; SITE-P7 applies the replacement.
15. Browser checks confirmed that the first focusable DOM element is the skip link; the theme control announces current and next themes, switches both token sets, and persists the explicit light choice across reload; live search returns both sample fixtures and their text records.
16. At 390px the native modal navigation retained keyboard focus, closed on Escape, reset `aria-expanded`, and returned focus to its trigger. The custom 404 route retained the global header and skip link and exposed Home, Book, and Essays recovery links.
17. Next.js 16.3.3's default Turbopack production path cannot evaluate the installed Fumadocs MDX 15.3.1 loader in this environment: its worker attempts to bind an internal port and reports the fixture modules as unresolved. The supported webpack path builds all nine routes successfully, so `pnpm build` explicitly selects `next build --webpack`. Fumadocs emits non-fatal webpack cache-invalidation warnings for its dynamic imports.
18. `scripts/check-private.sh` does not exclude ignored dependency or build directories, and installed third-party packages can match the external manifest. The immutable script exits 0 against the repository source tree when generated `node_modules` and `.next` directories are temporarily omitted; both directories were restored immediately afterward.
